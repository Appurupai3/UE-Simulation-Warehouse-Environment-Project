基於 Three.js 的 Web3D 智慧倉儲環境模擬系統

以瀏覽器 3D 視覺化呈現自動化倉儲作業，整合訂單管理、WebSocket 即時通訊、搬運車路徑規劃與演算法 Benchmark，協助觀察倉儲取貨流程與避障效率。

研究動機與目標

傳統倉儲流程不易即時觀察搬運車與貨物狀態。本系統以 Web3D 建置可互動的智慧倉儲模擬平台，讓使用者能在瀏覽器中輸入訂單、查看 3D 場景、執行取貨流程，並比較不同路徑規劃策略的效率與穩定性。

核心功能

3D 倉儲視覺化以 Three.js 呈現倉儲網格、貨箱堆疊、搬運車與出貨口。
即時訂單同步透過 WebSocket 將前端訂單與後端資料即時同步。
路徑規劃模擬支援 A*、BFS、貪婪與避障優先等策略比較。
Benchmark 分析用圖像化測試觀察步數、搬運流程與批次最佳化效果。

系統流程

01建立訂單使用者輸入貨物編號，產生待處理訂單。
02即時傳輸FastAPI WebSocket 保存並廣播訂單狀態。
033D 場景載入Three.js 載入倉儲格位、貨箱與搬運車模型。
04演算法規劃依貨物位置與障礙物計算取貨與回程路徑。
05模擬與評估播放搬運流程，紀錄完成訂單與 Benchmark 指標。

技術架構

  • Frontend：Vue.js 元件化介面，Three.js 負責 3D 渲染、場景控制與互動提示。
  • Backend：FastAPI 提供 REST API 與 WebSocket 連線，管理訂單、Benchmark 與貨物資料。
  • Algorithm：以 A*、BFS、Greedy、Obstacle-aware 等方法規劃路徑，並結合動態避障與死鎖檢測概念。
  • Data Flow：訂單從前端送出後由後端同步至 3D 模擬頁，完成後回寫訂單狀態。

演算法比較重點

原始順序依訂單輸入順序執行，作為基準線。
貪婪演算法優先選擇較近或成本較低的下一個目標。
A* 演算法以啟發式搜尋降低無效移動，提升路徑效率。
避障優先考慮搬運車與障礙物，降低碰撞與等待風險。
